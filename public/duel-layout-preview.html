3 ide yang dievaluasi

"Cari ide terbaik redesain layout pdf jika mode compare" — ini pertimbangannya:

  • IDE A — Duel Landscape (DIPILIH): A4 landscape + dua kolom tersinkronisasi (kiri = fokus, kanan = pembanding). Paling sesuai makna "compare", semua section otomatis berpasangan, tabel makin lega.
  • IDE B — Tabel Cermin (portrait): kolom A|B di-interleave dalam satu tabel. Ditolak — nama item dobel memaksa font ~4pt dan pairing per-ranking membingungkan (item #1 resto A ≠ item #1 resto B secara semantik).
  • IDE C — Label saja: tetap atas-bawah dengan penanda lebih jelas. Ditolak — tidak menjawab "kiri dan kanan".

Detail teknis singkat

  • Engine record-replay baru (pdf/columns.ts): tiap resto dirender ke "shadow" ber-lebar kolom, lalu digabung per halaman — pagination kedua kolom selalu sejajar.
  • Bagian yang lebih panjang otomatis bersambung ke halaman berikutnya dengan chip "NAMA (lanjutan)" di tiap kolom.
  • Table auto-fit menjamin tidak ada teks yang terpotong (aturan lama tetap berlaku) — tabel terpadat otomatis mengecilkan font, bukan memotong.
  • Mode Standar tidak berubah sama sekali (tetap portrait, byte-identical) — hanya mode Versus yang berubah.
  • Cache lama otomatis ter-mitigasi lewat rv 22 — export berikutnya pasti layout baru.
